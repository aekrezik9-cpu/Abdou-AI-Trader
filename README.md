# Abdou AI Trader

Android assistant for analyzing visible trading-chart screenshots and presenting educational CALL / PUT / WAIT signals.

## Scope
- Analyzes screenshots of the chart visible on screen.
- Presents a signal with reasoning and uncertainty.
- The user places trades manually.
- No automatic order execution and no direct access to Quotex internals or private APIs.
- No signal guarantees profit; test in demo mode first.

## Status
Project setup is in progress. Android UI, screen capture, and chart-analysis integration are not implemented yet.
